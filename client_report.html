Final Project Reports

From BYU-I Web Fundamentals

Client Report

Client Site - Home Page

I chose to have a website that helps BYU-I students understand certain parts about filing their taxes because I know absolutely nothing about the subject. Because I don't know anything about filing taxes, all of the images and text came from Google Gemini. Nearly all of the communication with my developer happened in class. There were no issues with communication, and my developer met my expectations for the site. Next time I hire a team to do a project for me, I will establish a clearer plan and expectations so that it is easier for the team to do the project.

Lead Developer Report

Lead Developer Site - Home Page

Once I had created the skeleton of the site and finished the portal page, I informed my junior developers in person about which page they were responsible for. I also put the site plan and their respective responsibilities in the GitHub repository. Whenever my team or I had questions about the project, I asked my client about them in class. There were no real issues with communication. I published the site using github pages and emailed my client a link to the website. While I hadn't worked with github much before this semester, this and one other class have given me the experience to make working with github much simpler.

Junior Developer Report

Hall of Fame Site - Best Animated Page

On this project, my team lead was sitting at my table, so there were no communication issues at all. I knew what was expected of me and was able to finish my page quickly and easily. I didn't run into any issues with github when adding changes to this site.

Junior Developer Report

Terraria Calamity True Melee Guide - Warnings Page

On this project, the original lead developer stopped showing up to class. The project was then handed off to another, and there wasn't much communication that happened. I did eventually ask for and receive my assignment, and was able to create my page. I did run into one issue when creating my page, as I had not pulled from the main branch recently enough to see that the other two junior developers had already finished their pages. The two other pages used the same general aesthetic, so I had to redo much of the styling I had done to make my page fit in better with the other pages.

General Reflections

For me, the most challenging part of this project was having to wait for a new lead developer on the previously mentioned site. Once I was given a responsibility and a plan of attack, it was fairly trivial to create the required page. What I enjoyed most about this project was getting to see the different ways that students in the class handled styling the websites. If I could do this project again, I would take more creative liberties on the sites I was given that had low expectations. After these projects, I feel a little more confident working on real-world projects. This is mostly because I now have a little bit more experience with GitHub.
